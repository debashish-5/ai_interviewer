
# AI Interviewer & Simulation Tool

An AI-powered tool designed to help students and candidates practice job interviews through interactive role-play and simulation. It simulates both interviewer questions and realistic candidate responses to give you real-time practice and insight into technical and behavioral interviews.

---

## 🎯 About the Project

Preparing for tech and job interviews can be overwhelming. This project provides an AI simulation environment that acts as both an **Interviewer** (asking relevant job-related questions) and a **Candidate** (simulating realistic interview answers). 

It serves as a valuable learning tool for **students, job seekers, and recruiters**:
* **For Students & Job Seekers:** Practice answering real interview questions, understand what interviewers look for, and refine your responses.
* **For AI Learners & Developers:** Learn how to implement multi-agent interaction and role-play simulation in Python.

---

## 🧰 Repository Structure

* **`ai_interview.py`**: Main script containing the core AI interviewer and candidate simulation logic.
* **`traveleragent/`**: Additional sub-module containing agent workflows for planning and research tasks.

---

## 🚀 Getting Started

### Prerequisites

* Python 3.8 or higher
* Required dependencies (install via terminal):
  ```bash
  pip install -r requirements.txt

```

*(If `requirements.txt` is missing, install your preferred LLM SDK, e.g., `openai`, `google-generativeai`, or `langchain` depending on your model setup).*

---

## 🛠️ Usage

1. **Clone the Repository:**
```bash
git clone [https://github.com/debashish-5/ai_interviewer.git](https://github.com/debashish-5/ai_interviewer.git)
cd ai_interviewer

```


2. **Set Up Environment Variables:**
Configure your API key (e.g., `OPENAI_API_KEY` or `GEMINI_API_KEY`) in your environment variables or a `.env` file:
```bash
export API_KEY="your-api-key-here"

```


3. **Run the Simulation:**
```bash
python ai_interview.py

```
